# L’Écho du Der — application mobile

Application iOS / Android construite avec Expo et React Native.

## Démarrage local

Prérequis : Node.js 22.13 ou plus récent.

```bash
npm install
npx expo install --fix
npm start
```

Le projet utilise Expo Router et le lecteur radio est fourni au niveau racine de l’application afin de rester actif pendant la navigation.

## Services reliés

- API : https://lechoduder.fr
- Flux MP3 : https://radio.lechoduder.fr/listen/echo-du-der/radio.mp3
